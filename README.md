# 澳科大遊戲設計工作台

[公開工作區](https://game.design.cab/)免登入使用，每位訪客的作品與模型設定保存在自己的瀏覽器，API Key 僅保留於目前頁面。支援連接本機 Ollama 或允許瀏覽器跨來源連接的 OpenAI 相容 API，生成、修改、試玩及匯出獨立 HTML 瀏覽器遊戲。

作品不會跨瀏覽器同步，可匯出 JSON 後在另一瀏覽器匯入。圖片及影片生成需供應商支援相容 API。Godot 執行與任意伺服器工具需使用桌面或受保護的管理工作台。

標識來源：[澳門科技大學](https://www.must.edu.mo/must/image/mobile-logo.png)、[目魚 AI](https://66.99.com/icons/icon-192.png)。
